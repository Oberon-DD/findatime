# Find a Time

Group availability polls, like when2meet, but with a real **Save** button. No accounts needed.

- Create a poll, pick the days and hours, and share the link.
- Everyone types their name, drags across their free times and presses Save.
- The group heatmap and the best times update for everyone.

## Setup
1. Run `supabase.sql` in your Supabase project (SQL Editor).
2. Put the project URL and the publishable (anon) key into `FAT_CONFIG` at the top of `index.html`.
3. Serve with GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`).
